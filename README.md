# Tata Steel Machine Failure Prediction

Predictive maintenance classification project to predict machine
failure using operational sensor data (temperature, torque,
rotational speed, tool wear).

## Google Colab Notebook
[Open in Colab](https://colab.research.google.com/drive/1ymyGe-aPolxo3yZLQLdn6__ksiudiihZ?usp=sharing)

## Tech Stack
Python, Pandas, NumPy, Scikit-learn, XGBoost, Matplotlib, Seaborn, Imbalanced-learn (SMOTE)
